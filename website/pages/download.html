Download for Linux x86_64 Release notes

The button downloads Kinoklip-x86_64.AppImage from the latest release on GitHub. Kinoklip is a beta: save often and keep a copy of your original files.

Run it

  1. Make it runnable

    With Gear Lever (easiest): install Gear Lever from your software centre and open the AppImage with it. Kinoklip appears in your application menu, and Gear Lever keeps it updated.

    By hand: right-click the file, choose Properties, open Permissions and tick “Is executable”, or run:

    chmod +x Kinoklip-x86_64.AppImage

  2. Start it

    Open it from the application menu, or double-click the file. The first window is the Project Manager, where you make your first project. Getting started takes it from there.

If double-clicking shows nothing, your system may lack FUSE, a small helper for AppImages. Install fuse3, or run:

./Kinoklip-x86_64.AppImage --appimage-extract-and-run

What your computer needs

SystemLinux on x86_64, X11 or Wayland. On ARM64 computers use Kinoklip-aarch64.AppImage where a release has one.
GraphicsOpenGL 3.3: AMD, Intel or NVIDIA, integrated graphics included.
OptionalVA-API for GPU decoding on Intel and AMD; a PipeWire or PulseAudio microphone for voice-over.

Updates, checks and other ways to get it

Updates. Kinoklip does not check for updates and never contacts anyone on its own. Gear Lever and AppImageUpdate read the release files on GitHub and update the AppImage when you ask.

Checksums. Each release has a SHA256SUMS.txt. Put it next to the AppImage and run:

sha256sum -c SHA256SUMS.txt

Nix, the dev build and building from source are described in Installing Kinoklip. The dev build is the next version before it is tested; try it only to help testing. Older versions stay on the releases page.
