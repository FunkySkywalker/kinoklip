AppImage

Three steps

  1. Download the file

    Get Kinoklip-x86_64.AppImage from the latest release. On an ARM64 computer, get Kinoklip-aarch64.AppImage instead.

  2. Make it runnable

    With Gear Lever (easiest): install Gear Lever from your software centre, then open the AppImage with it. Kinoklip appears in your application menu, and Gear Lever keeps it updated.

    By hand: right-click the file, choose Properties, open Permissions and tick “Is executable”, or run this in a terminal:

    chmod +x Kinoklip-x86_64.AppImage

  3. Start it

    Start Kinoklip from the application menu, or double-click the file. The first thing you see is the Project Manager, where you make your first project. The getting started guide takes it from there.

If double-clicking shows nothing, your system may be missing FUSE, a small helper for AppImages. Install fuse3, or run the file with --appimage-extract-and-run:

./Kinoklip-x86_64.AppImage --appimage-extract-and-run

Flatpak

Install it with Flatpak

The Kinoklip Flatpak repository has the same version as the AppImage, for x86_64 and ARM64, and Flatpak updates it for you. Kinoklip is not on Flathub.

  1. Add the repository

    Once per computer. It is signed, and Flatpak checks the signature:

    flatpak remote-add --user --if-not-exists kinoklip https://seniormatt.github.io/kinoklip-flatpak/kinoklip.flatpakrepo

  2. Install Kinoklip

    flatpak install --user kinoklip org.kinoklip.Kinoklip

    Start it from the application menu, or with flatpak run org.kinoklip.Kinoklip. Later versions come with flatpak update.

Software centre: in Discover or GNOME Software, open the repository file to add it as a source, then search for Kinoklip. The one-click file adds the repository and installs Kinoklip in one go. Kinoklip needs the KDE runtime, which comes from Flathub; if Flatpak says it cannot find it, set up Flathub first.

Help with testing

Dev builds

The next version, built from the newest code before it is tested. It has features that are not released yet and may have new bugs, so keep backups of your projects. It installs next to the normal Kinoklip and shares its settings.

Dev AppImage

Installs as “Kinoklip Dev” with a red icon. Open it with Gear Lever to get each new dev build in one click. The dev release page lists what is new.

Nightly Flatpak

The same newest code as a separate repository with a nightly branch, for x86_64 and ARM64:

flatpak remote-add --user --if-not-exists kinoklip-nightly https://seniormatt.github.io/kinoklip-flatpak/kinoklip-nightly.flatpakrepo
flatpak install --user kinoklip-nightly org.kinoklip.Kinoklip//nightly

Requirements

What your computer needs

System
Linux on x86_64 or ARM64X11 or Wayland. The AppImage and the Flatpak both come in both kinds.
Graphics
OpenGL 3.3AMD, Intel or NVIDIA, integrated graphics included. Almost every computer from the last ten years has it.
Helper
FUSE (fuse3)Only if the AppImage does not start; see above for the workaround. The Flatpak does not need it.
Optional
VA-API and a microphoneVA-API on Intel and AMD gives GPU decoding. PipeWire or PulseAudio microphones work for voice-over.

Updates and checks

Staying up to date

Updates. Kinoklip does not check for updates itself, and it never contacts anyone on its own. Flatpak updates the Flatpak version when you run flatpak update or update in your software centre. Gear Lever and AppImageUpdate read the release files on GitHub and update the AppImage when you ask them to.

Checksums. Each release also has a SHA256SUMS.txt file. To check your download, put it next to the AppImage and run:

sha256sum -c SHA256SUMS.txt

Nix and building from source are described in Installing Kinoklip.

Older versions stay on the releases page.

Build it yourself. Kinoklip is GPL software. The steps are in docs/building.md on GitHub.
