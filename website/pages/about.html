About this project

What Kinoklip is, who makes it, and how.

What it is

Kinoklip is a free, open source video editor for Linux with the layout, behaviour and shortcuts of DaVinci Resolve. It is a native C++ and Qt application that uses FFmpeg. It is a beta: it edits real projects, but it is young, so save often and keep your originals.

How it is made

This project was built with AI: almost all of the code, tests and documentation were written by AI, then checked and analysed by the project owner, who also directs and tests it. The icon was drawn by hand.

It is an independent project, not affiliated with Blackmagic Design, and it is written clean-room without any Blackmagic code or assets. The legal notes cover trademarks, codec patents and the warranty.

Privacy

Kinoklip has no telemetry, no analytics, no automatic crash reports and no update checks. A bug report shares system information only when you choose to send it. See the privacy page.

Support and contact

Kinoklip is free. If it is useful to you, a donation on Ko-fi helps keep it going. The Discord server is the place for questions and ideas; bugs go to GitHub.
