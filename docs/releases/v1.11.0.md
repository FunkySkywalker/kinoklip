### New
- New default look that follows DaVinci Resolve 21: the Kinoklip widget style (flat buttons, thin sliders, switches, tabs with a red underline, thin scroll bars) and the Kinoklip colour scheme; Breeze stays selectable in Preferences
- Interface fonts: Open Sans in Resolve's text sizes for every text, with the system font as an option (Preferences > UI Settings > Interface font)
- Audio: Voice Isolation on clips and track strips (local, optional AI)
- Audio: Noise Reduction effect (Auto Speech or Manual Learn)
- Audio: spectrum analyzer, phase correlation meter and goniometer, and Dim, Mono and Mute monitor controls
- Audio: loudness standards (EBU R128, ATSC A/85, YouTube, Podcast, Custom) with Loudness Range and a history graph
- Audio: automation lanes for volume, pan, mute, sends and effect parameters, with Read, Touch, Latch, Write and Trim modes
- Audio: Sends, Aux buses, bus pan and Phase Invert on every strip
- Audio: Gate and Expander with key filters and a key source per strip, for ducking music under speech
- Audio: Chorus, Flanger, Distortion, Stereo Width and a new Reverb with presets
- Audio: Effects Library and Inspector panels on the Audio page, effect slots on mixer tracks
- Compositing: Paint node (Stroke, Clone, Eraser, Smear)
- Compositing: 3D nodes (Image Plane 3D, Shape3D, Text3D, Merge3D, Camera3D, lights, Renderer3D)
- Compositing: particles (pEmitter, pGravity, pTurbulence, pMerge, pRender)
- Compositing: Fusion Composition transitions built on the page
- Compositing: Group, Macro, Underlay and Instance nodes, modifiers, expressions and parameter links
- Compositing: trackers (Mask Tracker, Point Follower, several patterns per Tracker), keyers (Ultra Keyer, Matte Control), warps (Grid Warp, Displace, Vector Distort), Soft Glow and Light Wrap
- Compositing: viewer Onion Skin, Region of Interest, Rulers, Safe Area, proxy and cache buttons
- Project Settings presets: save, load, import, export and a user default config
- Files with several audio tracks (OBS recordings) bring every audio stream in as its own linked clip

### Improved
- Color page: the viewer follows every drag live (wheels, bars, curves, qualifier, windows, fields), like Resolve
- Reversed clips and J shuttle play smoothly
- Render: Normalize audio lands within 0.5 LU with a true-peak limiter
- In-app help opens the guide on the website

### Fixed
- Arabic and other joined scripts in titles no longer show gaps at the joins; Write On reveals right-to-left text from the right (#12)
- Video at 23.976, 29.97 and 59.94 frames per second plays smoothly (also in 1.10.2)
- Hardware decoding: ProRes 4444 on Vulkan no longer comes back black, VAAPI devices are found with Qt 6.12, and hardware frames go to the GPU directly again
- Noise Reduction output lines up with the input, without a silent first block
- Buttons that open a menu show their arrow after the label instead of over it
