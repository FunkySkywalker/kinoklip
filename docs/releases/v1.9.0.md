## [Download Kinoklip 1.9.0 for Linux (AppImage)](https://github.com/SeniorMatt/kinoklip/releases/download/v1.9.0/Kinoklip-x86_64.AppImage)

Open it with [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) (or update it there), or make it executable (right-click > Properties > "Is executable") and double-click it. ARM64 computers: download [Kinoklip-aarch64.AppImage](https://github.com/SeniorMatt/kinoklip/releases/download/v1.9.0/Kinoklip-aarch64.AppImage) instead (it appears about half an hour after the release) and use it the same way. If double-clicking shows nothing, install `fuse3` or run it with `--appimage-extract-and-run`.

**New to Kinoklip? Read the [guide](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/readme.md).** Questions and ideas: join us on [Discord](https://discord.gg/pCeHnvDn3x). Website: [seniormatt.github.io/kinoklip](https://seniormatt.github.io/kinoklip/).

### New
- AppImage for ARM64 computers
- Several edit points selected with Ctrl+click and trimmed together: resize, roll, ripple, asymmetric trims, keys, E and typed offsets
- Preferences > System > Memory and GPU > Limit Kinoklip memory usage to

### Improved
- Kinoklip uses less memory: about a third less while playing, and far less when idle
- Smoother 10-bit HEVC playback on newer Intel graphics

### Fixed
- Every ripple edit keeps all sync-locked tracks in sync: ripple delete and cut of In/Out ranges, speed changes with Ripple Sequence, Paste Attributes > Speed, Vim deletes
- Ripple Cut and Delete of a marked range keep the playhead on its picture
- Change Clip Duration with Linked Selection off no longer moves the linked clip
- Alt-drag copy of a clip to another track shows up there
- Speed changes no longer slow down clips faster than 1000x
