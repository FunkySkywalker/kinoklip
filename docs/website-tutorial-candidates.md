# Candidate Resolve tutorials for a "Learn from Resolve tutorials" page

Status: a draft list only. Nothing here is on the website. The titles, channels and addresses come
from a web search and YouTube's public title data on 2026-11-19; **nobody has watched these
videos for this list**. Before any of them is published, every step in it has to be tried in Kinoklip
(a later polish round), and steps that do not work in Kinoklip have to be left out or listed
as differences. Do not copy a video's text or pictures; the page would only link to the video and
say which parts carry over.

Why these: they teach Resolve's Media, Cut, Edit, Color and Deliver basics, which Kinoklip copies.
Resolve 20 and 21 have newer AI and Fusion features that Kinoklip does not have; skip those parts.

## To check in the polish round

For each video: watch it with Kinoklip open on the same step, write down which steps work as shown,
which need another key or menu name, and which do not exist. Candidates 1, 2, 5 and 8 are the best
first ones to check because they stay on the basic pages. Videos 3, 4 and 7 were found as search
results with only a title and a short description to go on, so look at them before choosing.
